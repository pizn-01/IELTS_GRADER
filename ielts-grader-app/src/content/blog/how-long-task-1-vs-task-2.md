# How Long Should I Spend on Task 1 vs Task 2?

In the 60-minute IELTS Writing test, spend about **20 minutes on Task 1** and **40 minutes on Task 2**. Task 2 is worth twice as much, so overrunning the chart or letter and rushing the essay is a common reason capable candidates stay at 6.5.

This guide from **IELTS AI Tutor by IELTSGRADER** gives a minute-by-minute plan, shows what breaks under time pressure, and how to practise timing without guessing.

## How long on Task 1 vs Task 2? (timing table)

| Block | Time | Job |
|-------|------|-----|
| Task 1 plan | 2–3 min | Overview + key features (or letter bullets) |
| Task 1 write | 15–16 min | Hit 150+ words; clear overview |
| Task 1 check | 1–2 min | Numbers, tense, overview present |
| Task 2 plan | 4–5 min | Position + two body ideas |
| Task 2 write | 32–34 min | 260–290 words; full conclusion |
| Task 2 check | 2–3 min | Position consistency; 2–3 grammar fixes |

Total: **≈20 + ≈40 = 60**. Computer and paper tests use the same overall limit.

Weighting reminder: [how IELTS writing scores are calculated](/blog/how-ielts-writing-is-scored) and the [band score guide](/ielts-writing-band-score).

## Why Task 2 gets 40 minutes

Your final Writing band combines both tasks with **Task 2 weighted double**. A Band 7 essay with a Band 6 Task 1 still beats a Band 8 Task 1 with a Band 5.5 essay.

Examiner-style consequence: polishing every axis label on a chart while leaving Task 2 undeveloped caps Task Response — the criterion that most often blocks 7. See [stuck at 6.5](/blog/stuck-at-band-6-5-plateau).

## Before / after: timing mistakes under pressure

### Common Band 6.5 timing profile

- Task 1: 35 minutes (beautiful detail, no overview until the end)
- Task 2: 25 minutes (clear intro, one thin body, missing conclusion)
- Result: Task 1 looks “careful”; Writing overall stays mid-band

### Controlled profile

- Task 1: 18 minutes with overview in sentence two
- Task 2: 42 minutes with two developed bodies
- Result: even if Task 1 is 6.5, Task 2 can pull the average up

## Minute rules that prevent panic

1. **Wear a watch / use the on-screen timer.** Glance at 20:00 — Task 1 must be finishing.
2. **If Task 1 is incomplete at 22 minutes:** write a one-sentence overview and move on.
3. **Never “borrow” 15 minutes from Task 2** to perfect Task 1 vocabulary.
4. **Task 2 conclusion is not optional.** Leave 2 minutes; a missing conclusion hurts Coherence and can weaken Task Response.
5. **One grammar pass beats five vocabulary swaps** in the last minutes.

## Academic vs GT timing

Same clock. Different Task 1 jobs:

- **Academic:** select key features fast; overview early
- **GT letter:** cover all bullets; match tone (formal/semi/informal)

## Frequently asked questions

### How long should I spend on Task 1 vs Task 2?

About 20 minutes on Task 1 and 40 minutes on Task 2 inside the 60-minute Writing test, because Task 2 carries more weight.

### What if I need 25 minutes for Task 1?

Only if Task 2 still gets a full plan and conclusion. Habitually taking 30+ on Task 1 usually costs more overall band than it gains.

### Is timing the same for computer-delivered IELTS?

Yes — 60 minutes total for Writing. Use the on-screen clock the same way.

### Should I do Task 2 first?

Some candidates prefer Task 2 first to protect the higher-weighted task. If you do, still leave ~20 minutes for Task 1 and watch the clock strictly.

### How do I practise timing without a full mock?

Use two timers: 20 and 40. Even single-task drills should end when the alarm rings — unfinished work is data, not failure.
