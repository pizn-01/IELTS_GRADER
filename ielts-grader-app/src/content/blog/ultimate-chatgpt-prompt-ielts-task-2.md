# Ultimate ChatGPT Prompt for IELTS Task 2 Scoring

The ultimate ChatGPT prompt for IELTS Task 2 scoring forces **four criteria** (TR, CC, LR, GRA), demands descriptor-style reasons, and asks for rewrite targets — not a vague “What band is this?” Compliments. A strong prompt improves *format*; it does **not** turn a general chatbot into a calibrated IELTS examiner.

This guide from **IELTS AI Tutor by IELTSGRADER** gives a copy-paste evaluation prompt, weak vs strong before/after outputs, a verification checklist, and when to switch to a specialized checker. Practice estimates only — not an official IELTS result.

## What a good IELTS Task 2 scoring prompt must include

| Must-have | Why |
|-----------|-----|
| Four separate bands | Overall-only scores hide the bottleneck |
| Descriptor-linked reasons | “Good vocab” is not feedback |
| One rewrite target per weak criterion | Converts praise into practice |
| Word-count / task-coverage check | Stops under-length inflation |
| “Practice estimate, not official” | Honest framing |
| Ban empty encouragement | Reduces helpfulness bias |

Context on why weak prompts inflate: [why ChatGPT overestimates IELTS band scores](/blog/why-chatgpt-overestimates-ielts-band-scores) and [is ChatGPT accurate for IELTS writing?](/blog/is-chatgpt-accurate-ielts-writing).

## Ultimate ChatGPT prompt for IELTS Task 2 (copy-paste)

Paste this **first**, then paste your question + essay underneath.

```text
You are helping me practise IELTS Academic Writing Task 2. This is NOT an official IELTS score.

Score my essay using ONLY the public IELTS Writing Task 2 band descriptors for:
1) Task Response (TR)
2) Coherence and Cohesion (CC)
3) Lexical Resource (LR)
4) Grammatical Range and Accuracy (GRA)

Rules:
- Give a half-band score for EACH criterion (e.g. 6.0, 6.5, 7.0).
- Give an overall as the average of the four, rounded to the nearest half band.
- For EACH criterion: 2–3 sentences of evidence from MY essay (quote short phrases).
- Explicitly check: Did I answer EVERY part of the question? Approximate word count?
- Do NOT praise vaguely. If development is thin, say so even if vocabulary looks advanced.
- Identify the LOWEST criterion and give exactly THREE specific rewrite actions for it.
- End with: “This is a practice estimate only.”

Output format:
TR: X.X — reason
CC: X.X — reason
LR: X.X — reason
GRA: X.X — reason
Overall: X.X
Lowest criterion + 3 rewrite actions
Disclaimer line

Question:
[PASTE QUESTION]

Essay:
[PASTE ESSAY]
```

### Optional strictness add-on (one line)

Add under Rules if you want harsher output:

```text
- Prefer the lower half-band when evidence is mixed; do not round up for encouragement.
```

### Task 1 variant (one-line swap)

Change the opening to Academic Task 1 or GT letter and replace **Task Response** with **Task Achievement**. Keep the four-criterion structure. Task 1 practice: [Task 1 trends vocabulary](/blog/task-1-trends-vocabulary).

## Before / after: weak prompt vs ultimate prompt

### The essay (same for both)

**Question:** Some people believe unpaid community service should be compulsory in secondary school. To what extent do you agree or disagree?

**Essay (short mid-band practice sample):**  
Unpaid community service is sometimes proposed as mandatory because it may build character. I partly agree if programmes are capped and well designed. Service can teach teamwork, but compulsion can burden charities and feel exploitative if hours are excessive. Therefore limited compulsory service can help if quality is controlled. *(≈70 words — intentionally weak for contrast.)*

### Weak prompt → typical inflated reply

**Prompt:** `What IELTS band is this essay?`

**Typical reply pattern:**

> Band 7.0. Clear opinion and good vocabulary. Well done!

| Problem | Impact |
|---------|--------|
| No TR/CC/LR/GRA | You cannot train the real gap |
| Ignores under-length | Inflates Task Response |
| Empty praise | No rewrite target |

### Ultimate prompt → useful practice shape

**Expected shape** (numbers vary by model; structure should look like this):

| Criterion | Practice band (illustrative) | Why the prompt forces honesty |
|-----------|------------------------------|-------------------------------|
| TR | 5.0–5.5 | Under-length; almost no development |
| CC | 5.5–6.0 | Paragraph jobs incomplete |
| LR | 6.0 | Limited range; some clear wording |
| GRA | 6.0 | Simple control; little complexity |
| Overall | ≈5.5–6.0 | Average pulled down by TR |

Plus three rewrite actions on the lowest criterion — that is the win. Side-by-side methodology: [ChatGPT accuracy comparison](/blog/is-chatgpt-accurate-ielts-writing).

| Criterion | Prompt should force | Red flag if missing |

## Honest limits of the “ultimate” ChatGPT prompt

1. **Format ≠ calibration.** Better prompts reduce fluff; they do not lock a scoring model to IELTS.  
2. **Version drift.** Model updates change tone and strictness without warning.  
3. **Prompt gaming.** “Be harsh” helps once, then fails in a new chat — see [overestimate mechanisms](/blog/why-chatgpt-overestimates-ielts-band-scores).  
4. **No progress tracking.** Chat history is not a study plan. Specialized tutors store criterion trends ([IELTS AI Tutor](/ielts-ai-tutor)).  
5. **Neither tool is official.** Only your test centre result counts ([methodology](/methodology)).

| Need | Best ChatGPT prompt | Specialized IELTS checker |
|------|---------------------|---------------------------|
| Four-criterion format | Often achievable | Built-in |
| Stable bands across weeks | Weak | Stronger |
| Fix cards / rewrite UI | Manual | Built-in |
| Brainstorm / paraphrase | Excellent | Secondary |
| Official exam score | Neither | Neither |

## Common ChatGPT prompt mistakes (and fixes)

| Mistake | What happens | Fix |
|---------|--------------|-----|
| “What band is this?” | Optimistic overall only | Use the four-criterion template |
| “Be an examiner” with no rules | Roleplay without evidence | Require quotes from *your* essay |
| Scoring inside a long brainstorm chat | Polluted context | New chat every evaluation |
| Asking “Are you sure?” until it rises | Negotiation, not assessment | Re-run once in a fresh chat, then stop |
| Accepting praise with no rewrite list | Zero practice change | Demand three actions on the lowest criterion |

Candidates stuck at [Band 6.5](/blog/stuck-at-band-6-5-plateau) often fail the last row: they collect screenshots instead of rewriting. Band gaps explained: [Band 6 vs Band 7](/blog/band-6-vs-7-task-2).

## Checklist: is your ChatGPT evaluation usable?

- [ ] Four half-band scores present  
- [ ] Overall is average (not a vibes number)  
- [ ] Word count / task coverage mentioned  
- [ ] Lowest criterion named  
- [ ] Three concrete rewrite actions  
- [ ] Re-run in a new chat did not invent a new “story”  
- [ ] You will rewrite and re-check — not screenshot and stop  

If more than two boxes fail, stop negotiating with the chatbot and [check your essay free](/ielts-essay-checker).

## Frequently asked questions

### What is the ultimate ChatGPT prompt for IELTS Task 2?

A prompt that requires TR, CC, LR, and GRA half-bands, descriptor-linked evidence from your essay, a task-coverage/word-count check, and three rewrite actions on the lowest criterion — with a practice-only disclaimer.

### Will this prompt make ChatGPT as accurate as IELTS?

No. It improves structure and reduces empty praise. It does not create a calibrated official scorer. Use it for practice diagnosis shape, then verify with a specialized tool.

### Should I ask ChatGPT to “act as an IELTS examiner”?

You can, but the four-criterion rules matter more than the roleplay line. Roleplay alone still overestimates mid-band scripts.

### Can I use this prompt for Task 1?

Yes — swap Task Response for Task Achievement and state Academic chart or GT letter. Keep four criteria and rewrite targets.

### Is there a better option than prompting ChatGPT for bands?

For stable practice bands and rewrite workflows, use a descriptor-aligned checker. Keep ChatGPT for ideas and paraphrase. Compare approaches in [free vs paid IELTS checker](/blog/free-vs-paid-ielts-checker).
