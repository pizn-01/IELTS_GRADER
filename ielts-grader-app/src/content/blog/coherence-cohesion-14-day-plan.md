# 14-Day Plan to Improve Coherence & Cohesion

If your Task Response ideas are decent but examiners (or your tutor report) still mark **Coherence & Cohesion** at 6, you do not need more memorised linkers. You need cleaner paragraph logic, stronger topic sentences, and referencing that guides the reader.

This 14-day plan from **IELTS AI Tutor by IELTSGRADER** is built for candidates whose CC score is the bottleneck. Each day has one focus, one short drill, and a clear output. Pair it with the [essay checker](/ielts-essay-checker) twice during the fortnight.

## Before you start: diagnose

Submit one recent Task 2 essay and note:

- Is CC your lowest criterion?
- Do comments mention paragraphing, unclear progression, or mechanical linking?

If Task Response is much lower than CC, fix idea development first using [Band 6 vs 7 Task 2](/blog/band-6-vs-7-task-2). This plan assumes CC is the priority.

**Daily time:** 35–50 minutes. 
**Tools:** timer, notebook or doc, [Task 2 checker](/ielts-task-2-checker) on Days 7 and 14.

---

## Week 1: Structure and topic sentences

### Day 1: Map the four-paragraph job list

**Focus:** Every paragraph has one job.

**Drill:** For a discuss-both-views prompt, write only a plan:

1. Introduction, paraphrase + outline + opinion (if required)
2. Body 1: View A / reason 1
3. Body 2: View B / reason 2
4. Conclusion, summary + opinion restated

**Output:** One planning template you will reuse all fortnight.

### Day 2: Topic sentence clinic

**Focus:** First sentence of each body paragraph states the paragraph’s main idea.

**Drill:** Take three old essays. Rewrite only the topic sentences so a stranger could predict the paragraph content.

**Weak:** *Firstly, there are many advantages.* 
**Strong:** *One clear advantage of remote work is the reduction in daily commuting time.*

**Output:** Six upgraded topic sentences.

### Day 3: One idea per paragraph

**Focus:** Split mixed paragraphs.

**Drill:** Find a paragraph that discusses two unrelated points. Split it into two mini-paragraphs (even if short), each with its own topic sentence.

**Output:** Before/after paragraph pair.

### Day 4: PEEL without the acronym obsession

**Focus:** Claim → Explain → Example → Link back.

**Drill:** Write one body paragraph (120–150 words) using that flow. No more than two linker phrases.

**Output:** One controlled paragraph. Optional: check it with the [essay checker](/ielts-essay-checker) for CC notes only.

### Day 5: Referencing instead of repeating

**Focus:** *this, these, such, the former, this approach*

**Drill:** Rewrite a repetitive paragraph, replacing repeated nouns with precise references.

**Weak:** *Online courses help students. Online courses are flexible. Online courses are cheap.* 
**Strong:** *Online courses help students because they are flexible and often more affordable. This combination matters for learners who work part-time.*

**Output:** One rewritten paragraph with at least four reference links.

### Day 6: Stop mechanical “Moreover / Furthermore” chains

**Focus:** Meaning-based transitions.

**Drill:** Write a paragraph using only these links where needed: *because, however, for example, as a result, instead*. Ban *Moreover* and *Furthermore* for today.

**Output:** One paragraph that still feels connected.

### Day 7: Timed essay + CC review

**Focus:** Apply Week 1 under pressure.

**Drill:** 40-minute Task 2. Then submit to the [Task 2 checker](/ielts-task-2-checker).

**Review questions:**

- Did each body paragraph stay on one idea?
- Were topic sentences clear?
- Did linkers help or decorate?

**Output:** Criterion scores + three CC fix notes for Week 2.

## Week 2: Flow, cohesion devices, and transfer

### Day 8: Introduction → body bridge

**Focus:** The last sentence of the introduction should set up what follows without announcing “This essay will…”

**Drill:** Write five introductions that end with a clear opinion or map in natural language.

**Output:** Five intro endings.

### Day 9: Inside-paragraph order

**Focus:** General → specific → significance.

**Drill:** Take a Band 6-style paragraph (see [education sample](/blog/task-2-sample-band-6-education)) and reorder sentences into a cleaner sequence.

**Output:** Reordered paragraph + one-sentence explanation of the new order.

### Day 10: Contrast paragraphs that do not collide

**Focus:** “On the one hand / on the other hand” used with real opposition.

**Drill:** Plan two body paragraphs that genuinely contrast (cost vs access, freedom vs responsibility). Write topic sentences only, then full paragraphs.

**Output:** Paired contrast paragraphs.

### Day 11: Cohesion for opinion essays

**Focus:** Keep your position visible without repeating “I think” every line.

**Drill:** Write an agree/disagree body paragraph that maintains stance through language like *this policy, such a limit, that risk*, not repeated “I believe.”

**Output:** One stance-consistent paragraph. Compare with [Band 7.5 opinion sample](/blog/task-2-opinion-essay-band-7-5).

### Day 12: Conclusions that do not add new ideas

**Focus:** Summarise and close.

**Drill:** Write three conclusions for old essays. Delete any new example that appears only in the conclusion.

**Output:** Three clean conclusions.

### Day 13: Full rewrite of Day 7 essay

**Focus:** Transfer learning.

**Drill:** Do not write a new topic. Rewrite Day 7’s essay with better paragraph jobs, topic sentences, and referencing. Time limit: 40 minutes.

**Output:** Rewrite ready for final check.

### Day 14: Second timed essay + compare

**Focus:** Measure CC movement.

**Drill:** New prompt, 40 minutes. Submit both Day 13 rewrite and Day 14 new essay to the [essay checker](/ielts-essay-checker) or run a [mock writing test](/ielts-mock-writing-test) if you want Task 1 + Task 2 together.

**Compare:**

| Item | Day 7 | Day 14 |
|------|-------|--------|
| CC band | | |
| Clear topic sentences? | | |
| Mechanical linkers? | | |
| One idea per paragraph? | | |

**Output:** A short note: what improved, what still breaks under time pressure.

## Daily checklist (print or copy)

- [ ] Planned paragraph jobs before writing
- [ ] Topic sentence states the main idea
- [ ] Explanation before example
- [ ] Example linked back to the claim
- [ ] References used instead of noun spam
- [ ] No empty linker chains
- [ ] Conclusion adds no new argument

## What “good enough” Coherence looks like at Band 7

You do not need artistic transitions. You need:

1. A reader who can predict each paragraph from its first sentence 
2. Ideas that progress instead of restarting 
3. References that point clearly 
4. A conclusion that closes the same argument you opened 

Compare undeveloped Band 6 organisation in the [education sample](/blog/task-2-sample-band-6-education) with cleaner progression in the [technology Band 7 sample](/blog/task-2-sample-band-7-technology). Notice that Band 7 uses fewer decorative linkers, not more.

## Sample Day 4 paragraph (model)

**Prompt angle:** advantages of remote work.

> One clear advantage of remote work is the reduction in daily commuting time. When employees reclaim an hour previously spent travelling, they can start focused work earlier or protect time for family responsibilities. For instance, a designer who once crossed a city during peak traffic may now use that hour for deep project work before meetings begin. As a result, productivity gains come less from “working harder” and more from removing a structural drain on attention.

Why this helps CC: topic sentence states the job; explanation follows; example is tied back; final sentence states significance. Only one light transition (*As a result*).

## Sample weak paragraph to repair on Day 9

> Firstly, remote work is good. Moreover, people like it. Furthermore, companies save money. In addition, it is modern. Therefore it is the best option.

Repair goals: one main idea, remove linker spam, add explanation and a concrete example, end with significance. Do this repair as a timed 12-minute drill even outside Day 9.

## Timing under pressure (keep this visible)

Coherence collapses when planning is skipped. Non-negotiable for Days 7, 13, and 14:

| Minute | Action |
|--------|--------|
| 0–5 | Understand question + decide position |
| 5–8 | Label paragraph jobs (one line each) |
| 8–37 | Write |
| 37–40 | Check topic sentences + opinion consistency |

If you regularly start writing at minute 1, Coherence will stay Band 6 even after this plan.

## Transfer to Task 1 (bonus, optional Days 8 or 12)

Academic Task 1 coherence means overview → grouped details → comparisons, not a year-by-year dump. GT letters need purpose → bullets in order → clear request. If your module Task 1 CC is also weak, spend one optional session on [bar chart Band 7](/blog/task-1-bar-chart-band-7) or [formal letter checklist](/blog/gt-formal-letter-checklist) without abandoning the Task 2 focus of this plan.

## After Day 14

- If CC rose but TR is now lowest, switch to idea-development drills using [Band 6 vs 7 Task 2](/blog/band-6-vs-7-task-2). 
- If CC is still flat, slow down planning: spend 8 minutes outlining before every timed essay for one more week. 
- If overall remains 6.5 with CC as the cap, repeat Days 2–7 only before another full fortnight, see [plateau guide](/blog/stuck-at-band-6-5-plateau). 
- If CC improved under untimed conditions but fell in the timed Day 14 essay, your issue is performance, not knowledge, add two partial timed tasks next week.
